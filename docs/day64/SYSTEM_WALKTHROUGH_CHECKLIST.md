# Day 64 - System Walkthrough Checklist

## Objective
Provide a structured checklist for reviewing the complete hiring workflow.

## 1. ATS Stage

- [ ] Submit candidate resume.
- [ ] Verify resume extraction.
- [ ] Verify skill identification.
- [ ] Verify experience and education extraction.
- [ ] Generate ATS score.
- [ ] Verify score explanation.
- [ ] Check candidate ranking.

## 2. Screening Stage

- [ ] Open shortlisted candidate profile.
- [ ] Review screening responses.
- [ ] Verify screening evaluation.
- [ ] Check mandatory requirements.
- [ ] Confirm manual review option.

## 3. HR Interview Stage

- [ ] Schedule or initiate HR interview.
- [ ] Record candidate response.
- [ ] Verify response storage.
- [ ] Review HR evaluation.
- [ ] Confirm feedback availability.

## 4. Technical Interview Stage

- [ ] Initiate technical interview.
- [ ] Verify technical question relevance.
- [ ] Record candidate answer.
- [ ] Review technical evaluation.
- [ ] Verify score and feedback.

## 5. Decision Stage

- [ ] Review ATS result.
- [ ] Review screening result.
- [ ] Review HR evaluation.
- [ ] Review technical evaluation.
- [ ] Verify decision explanation.
- [ ] Confirm authorized human approval.
- [ ] Verify audit record.

## 6. Cross-System Checks

- [ ] Verify candidate ID consistency.
- [ ] Verify job ID consistency.
- [ ] Check API error handling.
- [ ] Check processing status.
- [ ] Check response time.
- [ ] Verify stored results.
- [ ] Verify access permissions.
