# Day 53: Recruiter-Friendly Report Format

## 1. Executive Summary

- Candidate name
- Candidate ID
- Target role
- Hiring Fit Score
- Final recommendation
- Confidence indicator

## 2. Evaluation Results

- ATS
- Screening
- HR Interview
- Technical Interview
- Machine Test

## 3. Candidate Strengths

Highlights supported by evaluation evidence.

## 4. Candidate Weaknesses

Areas requiring development or further assessment.

## 5. Risk Indicators

- Incomplete evaluation stages
- Unverified evidence
- Integrity alerts requiring review

Risk indicators are not proof of misconduct.

## 6. Behavioral Observations

Contextual observations only. No emotion or personality inference.

## 7. Final Recommendation

Decision and supporting explanation.

## 8. Recruiter Review

Human review is required before any final hiring action.

## Export formats

- JSON
- Markdown
- HTML
