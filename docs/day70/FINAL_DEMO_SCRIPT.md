# Day 70 - Final Zecpath AI Demonstration Script

## 1. Introduction

Good morning everyone.

Today I am presenting Zecpath AI, an AI-powered job portal and automated hiring platform.

The objective of this project is to organize recruitment activities using specialized AI modules that support candidate analysis and evaluation.

## 2. Problem Statement

Traditional recruitment involves several activities:

- Reviewing resumes manually.
- Identifying candidate skills.
- Comparing candidates with job requirements.
- Conducting screening.
- Evaluating interview responses.
- Organizing final hiring decisions.

These activities can require significant time and effort.

## 3. Proposed AI Solution

Zecpath AI organizes recruitment through specialized components:

- Resume Parsing.
- Skill Extraction.
- Experience Parsing.
- Education and Certification Parsing.
- Semantic Matching.
- ATS Scoring.
- Candidate Ranking.
- Screening AI.
- Interview AI.
- Decision Support.

## 4. System Architecture

The system follows a modular architecture.

The frontend communicates with backend services.

The backend coordinates AI processing components and data storage.

Each module handles a specific responsibility within the recruitment workflow.

## 5. Live Demo Workflow

Demonstrate the following sequence using the actual implemented application:

1. Open a candidate resume.
2. Explain the extracted candidate information.
3. Show the structured candidate profile.
4. Open a job description.
5. Explain skill and semantic matching.
6. Demonstrate ATS scoring.
7. Show candidate ranking.
8. Demonstrate screening results.
9. Explain the interview workflow.
10. Show decision-support information.

Important: If a stage is represented only by documentation or simulated data, explain that honestly rather than presenting it as a live feature.

## 6. ATS Scoring Explanation

The documented ATS scoring components include:

- Skill Match.
- Experience Relevance.
- Education Alignment.
- Semantic Similarity.

The scoring engine calculates an overall evaluation score.

The ranking engine uses the generated score to organize candidates.
