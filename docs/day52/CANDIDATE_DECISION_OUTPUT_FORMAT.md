# Day 52: Candidate Decision Output Format

Each candidate decision contains:

## Candidate
- Candidate ID
- Candidate name
- Target role

## Decision
- Recommendation category
- Hiring Fit Score
- Confidence Score
- Decision status

## Evidence
- Available evaluation stages
- Total evaluation stages
- Evidence verification status

## Risk
- Integrity flags
- Confirmed integrity issue status
- Contextual behavioral observations
- Risk explanations

## Explanation
- Summary
- Decision reasons
- Safeguards

## Human review
- Human approval requirement
- Reviewer rationale requirement
- Automatic hiring action disabled

The JSON object is the structured output for integration with
future dashboard and recruitment workflow modules.
