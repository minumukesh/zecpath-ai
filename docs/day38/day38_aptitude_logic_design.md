# Day 38 - Aptitude Logic Design

## Objective

Add reasoning-based and situational evaluation to the HR interview process.

## Workflow

Reasoning or Situational Question
             |
             v
Candidate Answer
             |
             v
Map Ideal Answer Structure
             |
             v
Compare Answer with Supplied Reference Points
             |
             v
Review Reasoning, Approach, Problem-Solving, and Clarity
             |
             v
Apply Configurable Weights
             |
             v
Generate Score Breakdown and Report

## Scoring Parameters

- Reasoning: 35%
- Approach: 25%
- Problem-solving: 25%
- Clarity: 15%

The engine normalizes weights and combines the component scores on a 0-100
scale. Reviewer-provided component scores are used in the demonstration.

## Answer Structures

Reasoning:
1. Understand the problem.
2. Explain the reasoning.
3. Show the steps.
4. State the conclusion.

Situational:
1. Describe the situation.
2. Explain the action.
3. Give the reason.
4. Describe the expected outcome.

Problem-solving:
1. Identify the problem.
2. Investigate the cause.
3. Compare solutions.
4. Explain the selected solution.
5. Describe how the result would be checked.

## Outputs

- Individual question results
- Reference points matched or missing
- Component score breakdown
- Configurable weights
- Final aptitude score
- JSON report
- Markdown report

## Important Limitations

Text indicators do not prove intelligence, reasoning ability, or suitability.
Reference points must be appropriate for each question and reviewed for
fairness. This prototype should support human evaluation rather than make
automatic hiring decisions.
