# Zecpath AI System

An AI-powered recruitment and hiring automation system.

## Overview

Zecpath AI is the AI component of an automated job portal and recruitment platform. It supports resume processing, candidate screening, ATS evaluation, AI interviews, scoring, and hiring recommendations.

## Key Features

- Resume extraction and classification
- Skill and experience extraction
- Job description parsing
- Semantic matching
- ATS scoring and candidate ranking
- Candidate eligibility evaluation
- Fairness assessment
- AI-assisted interviews
- Technical and behavioral evaluation
- Interview scoring and summaries
- Final hiring recommendations
- API integration

## Technology Stack

- Python 3.13
- FastAPI
- Pydantic
- spaCy
- RapidFuzz
- PyPDF
- python-docx
- JSON Schema
- Pytest
- Uvicorn
