# Day 27 - Confidence & Sentiment Signal Analysis

Objective:
Assess communication quality and text-based behavioral indicators.

Features:
- Hesitation pattern detection
- Response length measurement
- Speaking pace when duration is provided
- Positive, negative, and neutral lexical sentiment
- Uncertainty phrase detection
- Potential contradiction detection
- Communication strength indicators
- Behavioral indicators report

Limitations:
This implementation uses rule-based heuristics and a small sentiment
lexicon. It does not establish a candidate's true emotional state,
personality, honesty, or actual confidence. Contradiction detection
only checks a small set of explicit text patterns. Results must be
interpreted cautiously and should not independently determine hiring.
