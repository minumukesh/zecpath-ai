# Day 22 – HR Screening Dataset Creation

Structured HR screening questions for multiple roles.

Roles:
- Data Analyst
- Software Developer
- Business Analyst
- HR Executive

Categories:
- Introduction
- Education
- Experience
- Skills
- Location
- Salary
- Notice Period

Each question contains:
- Stable question ID
- Role
- Category
- Question text
- Language
- Supported languages
- Expected answer type
- Mandatory/optional flag
- Scoring importance
- Reusable template ID

Multilingual readiness:
- English base dataset
- Malayalam translation field
- Hindi translation field
- Translation keys for future localization
